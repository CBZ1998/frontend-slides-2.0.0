✦ 设计哲学

信念决定产品

  • 你不需要成为设计师才能做出美丽的东西。你只需要对你看到的做出反应。
  • 依赖是债务。一个 HTML 文件十年后仍能打开，但 2019 年的 React 项目？祝你好运。
  • 平庸是过眼云烟。每场演示都应该感觉是为你量身定制，而不是套用模板。
  • 注释是善意。代码应该向未来的你（或任何打开它的人）解释自己。
  • "展示，而非描述"——人们通过看到才能发现，而非通过抽象的选择。
